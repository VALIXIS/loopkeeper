# Contributing Guidelines

- **Never push directly to main.** The main branch must remain stable and demo-ready.
- **Work using feature branches.** Name branches eature/<your-feature-name>.
- **Pull Request required.** All changes must go through a PR to the develop branch.
- **PR must be tested before merge.** Ensure your code doesn't break existing functionality.
- **Keep commits focused.** Write clear and descriptive commit messages.
- **Do not introduce dependencies without justification.** Keep the project lightweight.
- **Do not modify another person's feature unnecessarily.** Coordinate with the team.

## Branch Model
- main = stable/demo-ready
- develop = integration branch
- eature/* = individual work
