# LoopKeeper

**Tagline:** From Meeting Promises to Completed Work.
**Description:** An AI-powered Meeting Accountability Engine that extracts, tracks, and manages action items across meetings.

**Current Project Status:** Production Ready

## High-Level Architecture
- **Web Client:** React + Vite + TypeScript
- **Mobile Client:** Flutter + Dart
- **Backend:** Python + FastAPI + SQLAlchemy + PostgreSQL + pgvector
- **AI/ML Layer:** Modular Python pipeline integrating a specialized SLM (Small Language Model) with LLM API fallback.

## Planned Technology Stack
- **Backend:** Python, FastAPI, Pydantic, SQLAlchemy, PostgreSQL, pgvector
- **Web:** React, Vite, TypeScript
- **Mobile:** Flutter, Dart
- **ML:** Python (Modular architecture for SLM experimentation)
